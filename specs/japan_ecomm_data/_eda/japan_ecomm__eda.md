## 7. Data Quality Red Flags

- ⚠️ **Column name typo:** `TRANSACTION_OUNT` in `MALL_MARKETS_YEARLY_REPORT` is missing a `C` — should be `TRANSACTION_COUNT`. Quote carefully in all SQL; rename in staging.
- ⚠️ **Undocumented CONDITION value `J`:** 7.1% of transactions (4,209 rows) and 8.7% of yearly records use condition `J`, which is not defined in the column comment (only S/A/B/C/D documented). Must be clarified — pricing suggests it is below D (possibly Junk).
- ⚠️ **CONDITION value `UNKNOWN`:** 197 rows in transactions have condition `UNKNOWN` — not in the documented enum. Likely a catch-all for missing condition data.
- ⚠️ **IS_SIM_FREE uses `LOCKED` but documentation says `LOCK`:** Column comment specifies `LOCK` as the value; actual data contains `LOCKED`. Standardize in staging.
- ⚠️ **NETWORK_RESTRICTION: 71.3% null** (42,268 of 59,320 rows) — majority unknown. Not suitable as a filter dimension without explicit null handling.
- ⚠️ **IS_SIM_FREE: 22.8% null** (13,509 rows) — significant unknown rate, especially on モール platforms where SIM status may not be disclosed.
- ⚠️ **AMAZON appears only in `MALL_MARKETS_YEARLY_REPORT`** (not in `MALL_MARKETS_MONTHLY_TRANSACTION`). These tables cannot be joined directly on `DATA_SOURCE` without a FULL OUTER JOIN or null handling.
- ⚠️ **MAKER is a constant column** (only `Apple` in both tables). Drop from staging or treat as a static filter.
- ⚠️ **8,236 rows with SUM_PRICE = 0** in yearly report (18.3%) — product-months with listings but no completed sales. Divide-by-zero risk in any per-unit pricing calculations.
- ⚠️ **16,239 rows (36%) with MODEL = `unknown`** in `MALL_MARKETS_YEARLY_REPORT` — substantial loss of model-level granularity; joining to transactions on MODEL will miss these.
- ⚠️ **VOLUME has 458 nulls** in transactions (0.77%) — affects composite key and GROUP BY logic.
- ⚠️ **MoM % columns can reach 3,400–9,330%** — products appearing for the first time generate unbounded MoM increases. Filter or cap in mart models.
- ⚠️ **`MALL_MARKETS_MONTHLY_TRANSACTION` covers only May 2025** despite the name implying broader coverage. The "yearly" report covers Jan–May 2025.
