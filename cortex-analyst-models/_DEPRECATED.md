# DEPRECATED

The Cortex Analyst YAML approach (uploading `.yaml` files to Snowflake stages via PUT/COPY INTO) has been replaced by **Snowflake Semantic Views**.

## New Approach

Semantic views are now created directly via `dbt build` using the `Snowflake-Labs/dbt_semantic_view` package with DDL-like SQL syntax. Verified queries are appended via a `publish_verified_queries()` post-hook macro.

**See:** `models/semantic/` for the new semantic view models.

## What Was This?

This directory contained Cortex Analyst YAML semantic model files generated by `scripts/generate_cortex_analyst_model.py`. These YAML files were uploaded to a Snowflake internal stage for use with `CORTEX_ANALYST_MESSAGE()`.

The files here are kept for reference only and are no longer actively maintained.
